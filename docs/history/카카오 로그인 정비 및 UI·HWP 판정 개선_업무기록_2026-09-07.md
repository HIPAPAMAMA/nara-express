# 카카오 로그인 정비 및 UI·HWP 판정 개선 · 2026-09-07

## 카카오 로그인·알림

- **닉네임 미표시 버그 수정**: 로그인 후 "님 연결됨"으로 닉네임이 안 뜨던 문제. 원인은 두 가지 — ① `/v2/user/me` 호출 시 잘못된 `property_keys` 파라미터로 `kakao_account`가 응답에서 통째로 빠짐, ② 더 근본적으로 로그인 요청 `scope`에 `talk_message`만 있고 `profile_nickname`이 빠져 있어 닉네임 동의 자체가 요청되지 않음. 두 곳 다 수정 후 실사용자 재연결로 확인 완료.
- **관심 키워드·저장내역 기기 간 동기화 추가**: 기존엔 localStorage에만 저장돼 기기 간 이어보기가 안 됐음. 새 회원가입 시스템 없이 기존 카카오 로그인(uid)을 재사용해 Vercel KV에도 저장(`functions/src/lib/userDataStore.js`, `/api/userdata/*`), 연결 시 로컬↔서버 합집합 병합(`web/src/lib/cloudSync.js`). 비로그인 사용자는 기존과 동일하게 동작.

## 대기업 참여제한 자동판정 (DTL-009·010)

- **구형 HWP도 Cloud Run 없이 자동판정**: 원래 LibreOffice(Cloud Run) 변환기가 필요해 GCP 결제 문제로 보류했던 것을, `@ohah/hwpjs`(Rust 네이티브 파서, napi-rs) npm 패키지로 대체 — 서버리스 함수 안에서 바로 처리. 실제 나라장터 hwp 2건(제한없음·제한있음)으로 검증. Vercel 배포 시 `dist/index.js`를 동적 경로로 require해서 정적 파일 추적(`@vercel/nft`)이 놓치는 문제가 있어 `vercel.json`의 `functions.includeFiles`로 리눅스 네이티브 바이너리를 명시적으로 포함해야 실제 배포본에서 동작함.
- **판정 키워드 확대**: "대기업 참여제한" 직접 문구 외에, 중소기업자 우선조달 근거법(중소기업제품 구매촉진 및 판로지원에 관한 법률·중소기업기본법)과 직접생산확인증명서·소기업소상공인확인서 요구 문구도 추가. 실제 교복 제조·구매 공고로 검증 — 기존 키워드로는 놓쳤던(false negative) 사례를 정확히 잡음.
- **평가분석(SC-03·SC-09) 추가 실측**: 마스킹으로 개인정보 문제 완화를 검토하다가, g2b.go.kr에서 평가위원별 점수 자체가 공고마다 구조화된 위치에 없고 기관 재량 공지사항(비정형 첨부파일)으로만 존재함을 확인 — DTL-007·008·SC-10과 같은 종류의 구조적 한계로 보류 유지 결정.

## UI/UX 개선

- 모바일 하단 네비·더보기 시트 아이콘을 이모지 → 단순 선 아이콘(`web/src/components/icons.jsx`)으로 교체
- PC 레이아웃 최대 너비 1152px → 1600px로 확대 (큰 모니터 여백 과다 피드백)
- PC 상단 메뉴 순서 재배치 — 자주 쓰는 화면(검색·키워드·경쟁사·쇼핑몰·저장내역) 우선, 설정성 화면(내 업체·알림설정)·미구현(평가분석)은 뒤로
- 헤더 로고 2배 확대, "API 정상" 상태에 마우스오버 툴팁 추가(어떤 API인지 명시) — 실제로는 5개 API 중 대표 1개(낙찰정보서비스)만 체크한다는 점도 사용자와 확인
- 모바일 핀치줌·더블탭줌 차단 — viewport meta만으론 최신 iOS Safari가 무시해서, CSS `touch-action` + JS 제스처 이벤트 차단으로 이중 처리
- 사업명·공고번호 검색창을 폼에서 제일 크게 확대, 이 폼은 항상 360px 고정 사이드바 안에서만 쓰이므로 뷰포트 기준 반응형(sm:) 대신 항상 세로 배치로 고정

## 기타 기능

- **SET-003 데이터 초기화**: 알림·설정 화면에 로컬 데이터 전체 삭제 버튼 추가, 카카오 연결 중이면 서버 동기화분도 함께 비움
- **조회 결과 캐시**: 같은 조건 재조회 시 서버·정부 API 재호출 없이 세션 캐시 재사용, 업체·기관·금액 같은 고급 필터만 바뀌어도 원본 재사용
- **SAV-003 제안·규격서 저장**: 실제 파일을 별도 저장소에 복사하는 대신, 기존 SAV-001 저장 인프라를 재사용해 첨부파일 원본 링크를 저장내역에 함께 보관 (Vercel Blob 등 새 인프라 추가 없이 해결)
